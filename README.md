# 小米视频纹理诊断页

版本：2026-09-18.2。打开 https://marroar.github.io/rvrland-video-texture-check/?v=20260918-2 ，确认标题 V2 后开始测试。保持前台，默认约 35–70 秒，完成后分段截图结果汇总。建议同一台设备分别测试小米浏览器和 Chrome。不能复制时直接截图即可。

检测包括静态四色图片对照、High/Main 页面内无控件和离屏视频、High 带控件旧版对照。每组单独运行并释放视频及 GPU 资源，每 250ms 记录 Canvas、WebGL 和抠绿结果；累计 GL 错误与异常，记录帧提交回调、时间变化及后台状态。原生播放是否可见仍需肉眼确认，时间变化不代表画面正常。

可选本机 NPC 视频，会增加两组测试，文件不会上传。默认仍为游客素材，不宣称覆盖全部 NPC，也不等同于完整 Three/Five 业务场景。

“有图像”仅表示像素统计不是全黑或全透明，不保证内容、颜色、方向正确。纯黑素材不适用此诊断。全透明与黑屏分别报告；抠绿可能合法产生透明。帧提交回调不能保证 Canvas/WebGL 可读取。不要仅凭一组结果认定硬件缺陷。
